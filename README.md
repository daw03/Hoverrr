# Hoverrr 🚁

¡Bienvenido a **Hoverrr**! 🎉

Hoverrr es tu destino definitivo para encontrar eventos de drones 🛸 para pilotos de todas las edades, niveles de experiencia y tipos de vuelo. Ya seas un principiante o un experto, aquí encontrarás el evento perfecto para ti.

## Tecnologías 🛠️

- **Backend**: Laravel API
- **Frontend**: Angular 

## Instalación 🚀
1. Clona el repositorio:
    ```bash
    git clone https://github.com/tuusuario/hoverrr.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd hoverrr
    ```
3. Instala las dependencias del backend:
    ```bash
    cd backend
    composer install
    ```
4. No te olvides el fichero .env:
    ```bash
    php artisan key:generate
    php artisan jwt:secret
    ```
5. Instala las dependencias del frontend:
    ```bash
    cd ../frontend
    npm install
    ```

## Uso 🏃‍♂️

1. Inicia el servidor de Laravel:
    ```bash
    php artisan serve
    ```
2. Inicia el servidor de Angular:
    ```bash
    ng serve
    ```
3. Abre tu navegador y visita `http://localhost:4200` para ver la magia de Hoverrr en acción.
